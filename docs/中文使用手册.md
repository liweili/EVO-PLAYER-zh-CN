# EVO Player 中文使用手册

这份手册面向“已经拿到中文版 EVO Player 安装包”的人，讲怎么装、怎么按键、每一项设置是什么意思、怎么让中文和 CJK 字体正常显示。

> 如果你手上只有官方英文版 `PPSA99039.ffpfsc`，中文界面是改不出来的——应用被编译成一个只读镜像。请看 [`集成说明.md`](集成说明.md)，按里面的步骤重新编译一次。

## 一、安装

### 前提

| 项目 | 要求 |
| --- | --- |
| 固件 | 已越狱，版本低于 13.60（开发基于 12.70） |
| 挂载工具 | ShadowMountPlus |
| FTP | 主机上有 FTP 服务，常见越狱载荷给的是 `2121` 端口 |
| U 盘（可选） | exFAT 或 FAT32，插在 `/mnt/usb0` |

### 从 ProsperoStore 安装

在主机上打开 ProsperoStore，搜 EVO Player，安装，然后到 **Games** 行启动。无需电脑、无需 FTP。

### 手动安装

1. 把 `PPSA99039.ffpfsc` 通过 FTP 传到 `/data/homebrew/`。
2. ShadowMountPlus 会在文件变化时挂载并自动启动；否则到 **Games** 行手动启动 EVO Player。

> **装新版本前必须先关掉 EVO。** 应用槽是常驻的，在运行中的实例下面换镜像，或者在旧实例上再叠一次启动，都可能把主机搞崩。先用 **退出 EVO**（左侧导航栏最后一项，或 **设置 → 系统与诊断 → 退出 EVO**）释放解码器和 GPU，再从系统切换器关闭。

### 中文字库（必看）

中文界面能否正常显示，取决于字体里有没有中文字形：

1. 准备一份包含简体中文的字体，建议 Noto Sans SC（OFL 许可）。
2. 放到主机 `/data/evoplayer/fonts/` 下，用 FTP 传即可。
3. 重启 EVO。运行时会从该目录加载 CJK 回退字体，并与包内自带的 `noto-fallback.huifont` 一起使用。

如果没有放字体，界面文字会显示成方块（“豆腐块”），但功能不受影响。字幕的中文显示同理——字幕渲染走的是同一套字体回退。

## 二、界面与导航

左侧导航栏自上而下：

| 项目 | 作用 |
| --- | --- |
| 主页 | 继续观看、最近媒体、各影视源的货架（Jellyfin / Emby / Stremio / Nuvio / Plex） |
| 浏览 | U 盘、内部存储、网络存储、收藏、最近文件 |
| 影视源 | Emby、Jellyfin、Plex、Stremio、Nuvio、IPTV 的服务器与账户管理 |
| 设置 | 六大分组，见第四节 |
| 关于 | 版本、更新检查、开发者与许可 |
| 退出 EVO | 释放解码器、音频、GPU 后退出 |

按 **左方向键** 随时打开导航栏。主页的影视源货架可以直接续播，不必先进影视源页面。

## 四、设置逐项说明

设置分六组，界面上的标题是中文，行内右侧是当前值，按 **× 键** 切换取值，按 **OPTIONS** 或 **○ 键** 返回。

### 视频与显示（解码器、超分辨率、120 Hz 与 HDR）

| 设置项 | 说明 |
| --- | --- |
| 默认画面比例 | 视频如何填满屏幕：适应（保留黑边）/ 填充（裁边铺满）/ 拉伸（变形铺满） |
| 播放续播 | 记住上次播放位置，下次接着看 |
| 视频解码器 | 用哪个后端解码：优先硬件（`sceVideodec2`）或优先软件（FFmpeg）；超出硬件能力的片源会自动回退 |
| 超分辨率 | 小于屏幕分辨率的片源实时放大：关闭 / Sharp（AMD FSR 1）/ AI（Anime4K 神经网络） |
| 深黑增强 | 把发灰的暗部压到 OLED 真正的黑，代价是暗部细节减少 |
| AI 网络 | 仅在超分辨率设为 AI 时可选：Standard / Large / Maximum（Maximum 为 PS5 Pro 优化） |
| 运动平滑 | 在 GPU 上把 24 fps 补到 60 fps；快速运动会出现软边与光晕，与 AI 超分叠加时更明显 |
| 120 Hz 输出 | 让 24 fps 电影走 5:5 下拉，消除抖动；每次切换刷新率电视会短暂黑屏 |
| 匹配视频帧率（实验性） | 向显示设备请求片源本身的刷新率，12.70 固件对电影回落 119.88 Hz |
| HDR 输出 | 自动（跟随电视）/ 关闭（按 BT.2390 曲线映射到 SDR）；起止时电视会短暂黑屏 |
| 网络缓冲 | 流媒体预读多远；高码率片源会自动降低预读量 |

### 音频（输出声道、扬声器与声音）

| 设置项 | 说明 |
| --- | --- |
| 音量增强 | 提高轻音量片源，会牺牲动态范围，强烈段落会被削顶 |
| 音频延迟 | 调整声音相对画面，修口型对不上 |
| 输出声道 | 立体声会把 5.1 / 7.1 下混为 2.0；多声道则输出独立 PCM |
| 音频直通 | 把 Dolby Digital、DD+（含 Atmos）、DTS、AAC 原样经 HDMI 送到功放解码；Dolby TrueHD 是实验项 |
| 环绕声测试 | 逐个声道发声，验证 5.1 / 7.1 接线 |
| 导航音效 | 方向键与按钮的操作音 |

### 字幕（偏好与外观）

| 设置项 | 说明 |
| --- | --- |
| 自动字幕 | 开始播放时自动加载字幕 |
| 默认字体样式 | Standard / Rounded / Bold / Condensed |
| 副字幕位置 | 第二条字幕的位置：叠在上方 / 屏幕顶部 |
| 副字幕颜色 | 黄 / 青 / 白，用来和主字幕区分 |

播放中可开双字幕：在字幕选择器里选第二条轨，主轨在下方、副轨在上方。字幕时间轴可用 **L2 / R2** 或触控板滑动实时微调。

### 界面与存储（主题、控制与浏览）

| 设置项 | 说明 |
| --- | --- |
| 主题 | 配色与强调色方案 |
| 手柄灯条 | DualSense 灯带跟随主题强调色 |
| 文件夹优先 | 文件浏览器排序时文件夹排在最前 |
| 键盘输入 | 用 EVO 自带虚拟键盘，或用 PS5 原生输入法 |
| 询问直播流 | 打开频道时先选格式与画质 |

### 系统与诊断

| 设置项 | 说明 |
| --- | --- |
| 兼容性报告 | 把编解码兼容性报告写到 `/mnt/usb0` |
| 调试叠加层 | 屏幕上显示硬件性能指标 |
| 开发者工具 | 系统诊断与性能统计 |
| 主机型号 | 只读，显示检测到的机型（PS5 / PS5 Pro / 未检测到） |
| 内存 | 只读，显示 GPU 内存预算与运行模式 |
| 软件更新 | 检查新版本；有新版本会下载、校验并安装，然后自动关闭 EVO |
| 退出 EVO | 释放解码器、音频与 GPU 后退出 |

### 实验性

标着“实验性”的功能仍在打磨，可能出现画面瑕疵。用不上就保持关闭。

## 五、常见问题

**界面还是英文？**
安装包必须是重新编译过的中文版。官方 `.ffpfsc` 改不了；见 [`集成说明.md`](集成说明.md)。

**界面文字是方块 / 豆腐块？**
`/data/evoplayer/fonts/` 里没有中文字体，或字体没有被加载。放一份 Noto Sans SC 后重启。

**字幕中文显示不出来？**
字幕走同一套字体回退，同样需要上面的中文字体。另外确认字幕文件本身的编码是 UTF-8。

**能不能不重新编译，直接给安装包打补丁？**
不能。`.ffpfsc` 是已链接好的只读镜像，文本常量已经固化在二进制里。

**想改某句译文？**
不用重新编译。把 `/data/evoplayer/lang/zh-CN.tsv` 放进主机（格式见集成说明），重启即生效，运行时覆盖表的优先级高于内置词表。

**装完新版本要注意什么？**
先退出 EVO 再替换镜像，否则可能崩溃。升级后 `zh-CN.tsv` 的覆盖关系依然有效，但新版本新增的文案需要补到文件里。
