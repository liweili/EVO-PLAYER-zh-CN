## 译文里必须原样保留的占位符

任何带 `%d`、`%s`、`%.1f`、`%llu` 的原文，译文里的占位符必须与原文**数量、类型、顺序完全一致**，否则程序会崩溃或输出乱码。例如：

```
RUNNING %s - CROSS TO CHECK FOR UPDATES   ->   正在运行 %s - 按 × 键检查更新
RENDER %d fps  /  DECODE %d fps  /  DROPPED %llu
    ->   渲染 %d fps / 解码 %d fps / 丢帧 %llu
```

`patch/tools/apply_zh_patch.py` 在包裹前会逐条比对占位符，不一致的条目直接跳过，不会写进源码。
